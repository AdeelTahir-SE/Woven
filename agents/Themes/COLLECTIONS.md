# WOVEN - Theme Collections

## Rule

Collections belong to themes. The active theme decides which Collections appear on the home page, collection strip, product sections, and collection routes.

## Classic Collections

Classic focuses on plain clothes and formal clothes.

Suggested collection directions:

- Plain Essentials
- Formal Edit
- Everyday Woven
- Refined Basics

## Summer Collections

Summer focuses on T-shirts, pants, and warm-weather clothing.

Suggested collection directions:

- Sky T-Shirts
- Light Pants
- Outdoor Ease
- Summer Sets

## Winter Collections

Winter focuses on jackets, hoodies, and cold-weather clothing.

Suggested collection directions:

- Ice Hoodies
- Cold-Air Jackets
- Layered Warmth
- Winter Essentials

## Collection Requirements

Each Collection should define:

- theme
- slug
- title
- short description
- product focus
- hero or feature image direction
- accent usage

Collections should avoid audience-specific language and should speak to general clothing customers.
